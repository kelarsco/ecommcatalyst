# EcommCatalyst

Single-file marketing site for EcommCatalyst (ecommcatalyst.com), an ecommerce growth agency.

- `index.html` contains all HTML, CSS and JavaScript (hash-routed pages).
- Pages include Home, Services, Our Work, About, Pricing, Resources, Contact, **Website Audit** and **Audit Report**.
- The free audit runs Google PageSpeed Insights from the visitor's browser, so it needs to be served from a normal domain.

## Before launch
- Set `CFG.email` in the script so the contact form delivers inquiries.
- Replace the remaining `[Insert ...]` placeholders (business email, social links, legal dates).

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
